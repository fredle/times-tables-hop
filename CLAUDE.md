# Times Tables Hop

Say the answer out loud to hop the frog across the road before the traffic arrives.

One game, two shells:

- **Web**: `server.js` serves `public/` and mints AssemblyAI streaming tokens
  (`npm start`, key in `.env`). Speech goes browser -> AssemblyAI.
- **iPhone**: `ios/` is a SwiftUI app (scaffolded by app-factory) that shows
  the same `public/` folder in a `WKWebView` and does speech recognition with
  Apple's Speech framework. No server, no AssemblyAI.

## Where things live

- `public/game.js`: the game and all four modes (times tables, numbers 1-9,
  letters, three-letter words). `public/numbers.js` and `public/reading.js`
  turn transcripts into answers; both have tests in `test/` (`npm test`).
- `public/voice.js`: `VoiceInput` (AssemblyAI) and `NativeVoiceInput` (iOS).
  The page picks the native one when `window.webkit.messageHandlers.voice`
  exists. Native code calls back into `window.__nativeVoice`.
- `ios/App/GameWebView.swift`: web view, the `hop://` scheme that serves the
  bundled `public` folder, and the message bridge. `SpeechListener.swift`: one
  recognition task per question, restarted on `reset`.
- `ios/project.yml` copies `../public` into the app bundle as a folder.

## iOS stack (fixed - do not change)

- SwiftUI, Swift 5 language mode, iOS 17.0+, iPhone only, portrait.
- The Xcode project is generated by XcodeGen from `ios/project.yml`. There is
  no `.xcodeproj` and no `Info.plist` in git: add Info.plist keys under
  `info.properties` in `project.yml`.
- `.github/workflows/ios.yml` compiles on a GitHub macOS runner and uploads to
  TestFlight. There is no Mac or Swift compiler on the dev machine, so CI is
  the first compile: use only APIs that exist on iOS 17 exactly as written.
- Factory-owned, leave as-is: `.github/workflows/ios.yml`; the `settings`,
  bundle ID, team, version and device family in `ios/project.yml`.
- No third-party Swift packages, analytics, tracking or accounts.
- Page audio is off inside the app (it fights the microphone for the audio
  session); feedback there is haptics.

## Releasing

`C:\devel\code\app-factory\factory.ps1 release times-tables-hop`. The workflow
only starts by itself for changes under `ios/`; the factory starts it by hand
when only `public/` changed.
